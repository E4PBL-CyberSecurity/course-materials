英単語の意味を答えるための事前学習

嶋 直樹　E4 PBL v2.1 / 2026-10-25

印刷・配布用PDF

実習で英単語を見たときに、一般的な日本語の意味を答えられることを目指します。英語の読み方や専門用語を、すでに知っている前提では進めません。

最初に使うのは英単語一覧の第1〜6組、合計60語です。1回に1組を扱い、その中でも5語ずつに区切ります。紙でも画面でも学べます。ThinkPadを起動したり、コマンドを実行したりする必要はありません。

学習前に分かる語を確かめる

Section titled “学習前に分かる語を確かめる”

まず、一覧を見ずに次の語の意味を日本語で書いてください。分からなければ空欄のままで構いません。これは学習前の確認で、成績を下げるための課題ではありません。

表I-1 学習前の確認
英単語自分で答えた意味
save
size
already
sure
current
reset

答えを写す前に、「答えられた語」「読めるが意味を言えない語」「初めて見た語」を区別してください。分からなかった語から学べば十分です。

5語を読んでから意味の欄を隠す

Section titled “5語を読んでから意味の欄を隠す”
  1. 一覧の1組から5語を選び、英語と一般的な意味を対応させます。発音が分からなければ教員に尋ねてください。カタカナの発音だけを答えとして覚えないようにします。
  2. 「一般的な意味」と「実習での使われ方」の欄を紙などで隠します。英語だけを見て、日本語で意味を言うか、書きます。
  3. 欄を開き、自分の答えと比べます。例えばsizeに「サイズ」とだけ答えていたら、「大きさ」と言い直します。
  4. 間違えた語だけを、意味を確かめてからもう一度答えます。綴りを何回も書き写す必要はありません。
  5. 残りの5語も同じように学び、最後に10語の順を変えて答えます。

例えば、saveの一般的な意味は「保存する、取っておく」です。saveというコマンドの役割は「設定を保存する」です。まず単語の意味を答え、次に実習で何を保存するかを確かめます。

次の機会にもう一度思い出す

Section titled “次の機会にもう一度思い出す”

学んだ直後だけでなく、翌日など次に学習するときにも、前の組から答えにくかった語を選び、意味の欄を隠して答えます。まだ答えられない語は一覧を見て学び直します。

表I-2 1組分の学習記録
記録すること記入欄
学習した組・日付
初めは意味を答えられなかった語
練習後に一覧を見ずに答えた語と意味
次の機会に再確認した語と意味
まだ質問したい語

教員は口頭で答えた場合も確認できます。記録欄を埋めることだけで、意味を答えられるようになったとは判断しません。

単語を短い表示の中で読む

Section titled “単語を短い表示の中で読む”

単語の意味を答えられたら、表示メッセージの読み方へ進みます。先に次の例で練習してください。表示例を読む学習なので、実際に接続エラーを起こす必要はありません。

例：already exists

alreadyは「すでに」、existsは「存在する」です。組み合わせると「すでに存在する」となります。existsはexistの形が変わったものです。

次の練習は、答えの段落を隠してから取り組みます。

  • 練習1：name、size、typeの一般的な意味を、それぞれ日本語で答える。
  • 練習2：deniedとconnectingを元の形に戻し、一般的な意味を答える。
  • 練習3：No configuration changes to commitは、何がないと伝えているか答える。
  • 練習4：Create / Reset Databaseのcreate、reset、databaseの意味を答える。実際のボタンは押さない。

練習の答えを確かめる

Section titled “練習の答えを確かめる”

練習1は「名前」「大きさ」「種類」。練習2はdeny「拒否する」、connect「つなぐ」。練習3は「確定・反映する設定変更がない」。練習4はcreate「作る」、reset「元に戻す」、database「情報を整理して蓄えるもの」です。

違う言い方でも意味が同じなら構いません。「ファイル」「パスワード」のように日本語でも定着している語は使えます。ただし、sizeを「サイズ」、deniedを「ディナイド」と読むだけでは、意味の説明になりません。

学習後に確認課題へ取り組む

Section titled “学習後に確認課題へ取り組む”

教員が指定したときに、確認課題へ進みます。まず一覧や辞書を見ずに答え、その後、分からなかった語を学び直してください。スペルの書き取りやコマンド全文の暗記は求めません。

読めない語・意味が曖昧な語が残ったら、語を指して質問してください。一般的な意味が分かっても、削除や上書きの確認で迷う場合は、手順書と教員の確認を使って作業します。
