11. WSLでKali Linux・Ubuntuを準備する

嶋 直樹　E4 PBL v2.1 / 2026-10-25

印刷・配布用PDF

ルーター・DNS・VS Codeの準備が終わったWindows PC2台で、Linux環境を用意する。PC1のUbuntuをサーバー役、PC2のKali Linuxを通信の確認用として使う。

WSL本体をインストールする

Section titled “WSL本体をインストールする”

対象はIntel/AMD 64ビットPC、Windows 11 22H2以降、WSL 2.4.10以降。「スタート」→「設定」→「システム」→「バージョン情報」を開き、「Windowsの仕様」でWindowsの版を確認する。次に「スタート」を右クリックして「タスクマネージャー」を開き、「パフォーマンス」→「CPU」で「仮想化」が「有効」であることを確認する。

Windows・自分のPowerShell：

wsl --versionはWSL本体の版を表示する。「WSL バージョン」が2.4.10以降であることを確認する。

wsl --list --verboseは、自分のWindowsアカウントに登録されているLinuxの名前・状態・WSLの方式を表示する。Kali LinuxとUbuntuが登録済みの場合の表示例：

  • NAME：Linuxの登録名。kaliやUbuntu-26.04の行があれば、そのLinuxは導入済み。
  • STATE：Runningは起動中、Stoppedは停止中。導入済みかどうかの確認では、どちらでもよい。
  • VERSION：そのLinuxを動かすWSLの方式。授業では2を使う。UbuntuやKali LinuxのOSの版、WSL本体の2.4.10などの版とは別である。
  • 名前の左の*：名前を指定せずwslを実行したときに起動する、既定のLinuxを示す。

「インストールされているディストリビューションがありません」などと表示されたら、Linuxはまだ登録されていない。初回の準備ではこの状態でもよい。これはWSL本体の未導入とは異なる。

WSL本体が未導入の場合だけ、自分のWindowsアカウントで「スタート」を右クリックし、「ターミナル（管理者）」を選ぶ。「ユーザー アカウント制御」が表示されたら「はい」を選び、PowerShellで次を実行する。

再起動を求められたら作業を保存して再起動する。自分のWindowsアカウントで「ターミナル」を開き、PowerShellで次を実行する。

Linuxの登録はWindowsユーザーごとに別なので、以降も自分のWindowsアカウントで作業する。

Kali Linuxのイメージを取得する

Section titled “Kali Linuxのイメージを取得する”

本授業は公式配布元から取得・照合済みのWSLイメージを実験室サーバーからコピーして使う。共有へ到達するには第9章の戻り経路とサーバー側の受付が必要。

  1. エクスプローラーで左側の「ダウンロード」を開く。「新規作成」→「フォルダー」を選び、WSL-Imagesという名前のフォルダーを作る。
  2. 「表示」→「表示」→「ファイル名拡張子」をオンにし、ファイル名の末尾まで表示する。
  3. アドレス欄に\\192.168.1.10\images\kaliを入力する。認証を求められたら、教員から配布された資格情報を使う。
  4. kali-linux-2026.2-wsl-rootfs-amd64.wslを右クリックし、「コピー」を選ぶ。
  5. 左側の「ダウンロード」からWSL-Imagesを開く。ファイル一覧の空いているところを右クリックし、「貼り付け」を選ぶ。
  6. コピーの進行画面が閉じ、コピー先にkali-linux-2026.2-wsl-rootfs-amd64.wslが表示されたらコピー完了。

コピーしたファイルを照合する

Section titled “コピーしたファイルを照合する”

ハッシュ値は、ファイルの内容から計算する値である。コピーした内容が配布元と同じかを確認するため、SHA256という方式で計算した値を照合する。

エクスプローラーでコピー先のWSL-Imagesを開き、ファイル一覧の空いているところを右クリックして「ターミナルで開く」を選ぶ。PowerShellで次を実行する。ファイル名の前の.\は、今開いているフォルダー内のファイルを指定する表記である。

結果のAlgorithm欄がSHA256、Hash欄の64文字が次の値とすべて一致すれば照合完了。英字の大文字・小文字は区別しない。Hash欄が表示されなければ、ファイル名と、WSL-Imagesでターミナルを開いたかを確認する。不一致ならインストールせず、エクスプローラーでコピーし直す。

Kali Linuxをインストールし、ユーザーを作る

Section titled “Kali Linuxをインストールし、ユーザーを作る”

上で開いたPowerShellでwsl --list --verboseを実行し、NAME欄にkaliの行があるかを見る。あれば再インストールせず、その環境を起動して下のOS名と版を確認する。行がない場合だけ新規インストールする。

初回起動時のユーザー作成画面では、次の値を入力する。各項目で入力後にEnterキーを押す。

  1. ユーザー名：kali。
  2. パスワード：kali。
  3. パスワードの再入力：もう一度kali。

パスワードの入力中は文字が表示されないが、正常な動作である。作成後、whoamiの結果がkaliであり、cat /etc/os-releaseにKali Linuxの名前と版が表示されることを確認する。exitでPowerShellへ戻る。

Kali Linuxの登録名はkali。

サーバー役Ubuntuのイメージを取得する

Section titled “サーバー役Ubuntuのイメージを取得する”
  1. エクスプローラーのアドレス欄に\\192.168.1.10\images\ubuntuを入力する。
  2. ubuntu-26.04.1-wsl-amd64.wslを右クリックし、「コピー」を選ぶ。
  3. 左側の「ダウンロード」からWSL-Imagesを開き、ファイル一覧の空いているところを右クリックして「貼り付け」を選ぶ。
  4. コピーの進行画面が閉じ、コピー先にubuntu-26.04.1-wsl-amd64.wslが表示されたらコピー完了。

Kali Linuxと同様に、コピーした内容の一致を確認する。WSL-Imagesの空いているところを右クリックして「ターミナルで開く」を選び、PowerShellで次を実行する。

Algorithm欄がSHA256、Hash欄の64文字が次の値とすべて一致すれば照合完了。英字の大文字・小文字は区別しない。不一致の場合は、Kali Linuxと同様にエクスプローラーでコピーし直す。

Ubuntuをインストールし、ユーザーを作る

Section titled “Ubuntuをインストールし、ユーザーを作る”

上で開いたPowerShellを使う。先ほどの一覧のNAME欄にUbuntu-26.04の行があるかを見る。あれば再インストールせず、その環境を起動して下のOS名と版を確認する。行がない場合だけ新規インストールする。

初回起動時のユーザー作成画面では、次の値を入力する。Windowsのユーザー名が候補に表示されても、そのまま確定せず、ubuntuと入力する。ユーザー名を統一し、ユーザー名を含む操作やパスを全員が手順書の記述どおり使えるようにするためである。

  1. ユーザー名：ubuntu。
  2. パスワード：ubuntu。
  3. パスワードの再入力：もう一度ubuntu。

各項目で入力後にEnterキーを押す。パスワードの入力中は文字が表示されない。作成後、whoamiの結果がubuntuであり、cat /etc/os-releaseにUbuntu 26.04が表示されることを確認する。exitでPowerShellへ戻る。

PowerShellでwsl --list --verboseを実行する。NAME欄でkaliとUbuntu-26.04の行を探し、両方のVERSION欄が2なら確認完了。STATE欄はRunningでもStoppedでもよい。名前がなければ登録が完了していない。VERSIONが1ならWSL 1なので、次のミラーモード設定へ進まず教員に確認する。稼働するWSLのディスクはローカルディスクに置き、SMB共有上には置かない。

ミラーモードを設定する

Section titled “ミラーモードを設定する”

Windowsでnotepad.exe "$env:USERPROFILE\.wslconfig"を実行する。既存ファイルは別名でバックアップし、既存項目を残して[wsl2]節に次の値を設定する。同名の節や項目を重複させない。

ファイル名を.wslconfig.txtにしない。設定はそのWindowsユーザーの全WSL 2環境に適用される。WSL内の作業を保存し、PowerShellから再起動する。

Ubuntu内：

mirrored、実験用IP、経路、名前解決を確認する。nslookupがなければsudo apt updateとsudo apt install -y dnsutilsで導入する。Kali Linuxでも同様に確認する。Ubuntu内へWindowsとは別の班LAN用固定IPを追加しない。

Kali Linux・Ubuntuのトラブルを切り分ける

Section titled “Kali Linux・Ubuntuのトラブルを切り分ける”

完了の確認

Section titled “完了の確認”

Linuxの登録名・版、whoamiの結果がKali Linuxではkali、Ubuntuではubuntuであること、ミラーモード、班LANのIP・経路、指定DNSと通常の名前解決の結果を記録する。

Windowsの版の確認：Microsoft公式：Windowsデバイスに関する情報を検索する。
