2. 実験用ネットワークを確認する

嶋 直樹　E4 PBL v2.1 / 2026-10-25

印刷・配布用PDF

実験LANへ配線する前に、ThinkPadルーター・スイッチ・Windows PCの役割と、自班のアドレスを確認する。

通信が通る順序を確認する

Section titled “通信が通る順序を確認する”

自班のWindows PC → 班専用スイッチ → ThinkPadの内側NIC → 外側NIC → 共通スイッチ → 共通GW → インターネット、の順に接続する。他班への通信は共通LANから相手班ルーターへ進む。

スイッチは同じLANの機器をつなぐ。ルーターは異なるLAN間の通信を中継する。ThinkPadはインストール先USBに保存したVyOSを起動してルーターとして使い、Windows PC2台は操作端末として使う。

アイコン出典：Cisco Network Topology Icons（Router / Workgroup switch）。図では機器の役割を示す記号として使用しており、実機がCisco製品であることや、Ciscoによる公認を示すものではない。

自班のIPを記録する

Section titled “自班のIPを記録する”
表2-1 各班のIPアドレスと担当ドメイン
班外側eth0内側eth1・端末のGW/DNSPC1（A）／PC2（B）ドメイン
1192.168.1.21192.168.21.1192.168.21.10／.11alf.lab
2192.168.1.22192.168.22.1192.168.22.10／.11bra.lab
3192.168.1.23192.168.23.1192.168.23.10／.11cha.lab
4192.168.1.24192.168.24.1192.168.24.10／.11del.lab

すべて/24（サブネットマスク255.255.255.0）。PC2の.11はPC1と先頭3組が同じ。共通LANは192.168.1.0/24、共通GW・上流DNSは192.168.1.1、配布サーバーは192.168.1.10。

班ルーターではNATを設定しない。共通GWに各班LANへの戻り経路があり、インターネットへ出るときに共通GWがNATする。戻り経路と共通GWの許可設定は教員が準備する。同じIPを使うE3機器は同時に接続しない。

PC1のUbuntuをサーバー役web、PC2のKali Linuxを通信の確認用端末atkとして使う。WSLのミラーモードではWindowsと同じ班LANのIPを利用するため、UbuntuやKali Linuxに別の固定IPを追加しない。

任意でDHCPサービスを追加する場合は、各班LANの.100～.199を自動配布用に使う。PC1の.10・PC2の.11と重ならず併用できる。

完了の確認

Section titled “完了の確認”

班番号、外側IP、内側IP、PC2台のIP、ドメインを記録する。この段階では、本体のLANポートがeth0かどうかは未確認である。第6章でLANケーブルを挿し替え、eth0・eth1のどちらのリンク表示が変わるかを見て確認する。
