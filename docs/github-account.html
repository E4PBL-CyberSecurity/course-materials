学校のメールアドレスでGitHubを利用する

嶋 直樹　E4 PBL v2.1 / 2026-10-25

印刷・配布用PDF

E4 PBL サイバーセキュリティ／学生用手順書／2026年10月16日版

GitHubは、プログラムや教材のファイルを保存し、変更の履歴を残して共同作業するサービスです。授業では自分のアカウントで参加します。班で一つのアカウントを共有しません。

初めて使う人は第1～6節を順番に進めてください。既にアカウントがある人は、第2節の「既存アカウントを使う場合」から進めます。 困ったときは第7節を参照し、解決しなければ担当教員に相談してください。画面の表示は更新されることがあるため、英語の項目名も併記しています。

1. 準備する

Section titled “1. 準備する”
  • 学校から配布された、自分のメールアドレス。学校メールを開き、受信できることを確認します。
  • インターネットにつながるPCとブラウザー。
  • 自分が管理するスマートフォン等の認証アプリ。既に利用している認証アプリがあれば、それを使えます。用意できない場合は二要素認証の設定前に教員へ相談します。

共用PCでは自分のWindowsアカウントで作業してください。パスワードや認証情報をブラウザーへ保存する場合は、自分だけが利用する端末に限ります。

2. アカウントを作る

Section titled “2. アカウントを作る”

初めてGitHubを使う場合

Section titled “初めてGitHubを使う場合”
  1. ブラウザーでGitHubの登録ページを開きます。アドレスがhttps://github.com/で始まることを確認します。
  2. メールアドレスとパスワードを入力する登録欄を使います。本手順ではGoogle・Apple経由の登録は使いません。
  3. Emailに学校のメールアドレスを入力します。学校メールの画面から確認し、末尾まで正確に入力してください。
  4. PasswordにGitHub専用のパスワードを設定します。学校アカウントのパスワードは使い回しません。画面の条件を満たす、十分に長いものを選びます。
  5. Usernameにユーザー名を入力します。これはGitHub上で公開される名前で、プロフィールのURLにも使われます。英数字とハイフンを使い、既に使われている名前は避けます。学籍番号や学校メールアドレスをそのまま使う必要はありません。
  6. Country/Regionは実際の居住国・地域を選びます。日本に住んでいる場合はJapanです。
  7. 人による操作の確認が表示されたら、自分で解きます。利用規約とプライバシーに関する案内を確認し、同意できる場合は画面の登録ボタンで進みます。

本授業のアカウント準備に、有料プラン、クレジットカード登録、学生向け特典の申請は不要です。

ここまでの確認：学校メールを入力し、自分のユーザー名を決めて登録を進められた。 登録とメール認証は別の作業です。続けて第3節を行います。公式：アカウントの作成

既存アカウントを使う場合

Section titled “既存アカウントを使う場合”

自分の既存アカウントに、次の操作で学校メールを追加します。

  1. 自分のアカウントにログインします。
  2. 右上のプロフィールアイコン → Settings → Emailsを開きます。メール設定を開く
  3. Add email addressに学校メールを入力し、追加します。
  4. 学校メールに届いた案内でメール認証を済ませます。認証済みの学校メールを登録した状態で第4節へ進みます。

学校メールを追加しても、既存のメールを削除する必要はありません。公式：メールアドレスの追加

3. 学校メールを認証する

Section titled “3. 学校メールを認証する”
  1. 学校のメールを開きます。GitHubから届いた登録・確認メールを探してください。
  2. GitHubの登録画面がコード入力を求めている場合は、メール内の確認コードを入力します。認証リンクが案内されている場合は、そのリンクから確認します。
  3. 自分のアカウントでSettings → Emailsを開き、学校メールの認証が完了していることを確認します。Unverifiedが残っている場合は、まだ完了していません。

確認コードは他の人へ送らず、自分で入力します。

4. メールアドレスを公開しない設定にする

Section titled “4. メールアドレスを公開しない設定にする”
  1. Settings → Emailsを開きます。
  2. Keep my email addresses privateにチェックを入れます。
  3. プロフィールに学校メールを公開表示する必要はありません。

この設定を使うと、GitHubのWeb画面から行うファイル変更には、GitHubが用意する公開用のnoreplyアドレスが使われます。公式：変更履歴に使うメールアドレス

5. 二要素認証を設定する

Section titled “5. 二要素認証を設定する”

二要素認証（2FA）は、パスワードに加えて認証アプリなどでも本人確認する仕組みです。既に有効な人は、現在の方法でログインできることを確認してください。

  1. 右上のプロフィールアイコン → Settings → Password and authenticationを開きます。認証設定を開く
  2. Two-factor authenticationのEnable two-factor authenticationを選び、認証アプリ（TOTP）を使う方法で進めます。
  3. 自分の認証アプリでGitHubを追加し、GitHub画面のQRコードを読み取ります。学校メール用の既存登録を削除・上書きしないでください。
  4. アプリに表示されたGitHub用の確認コードを、GitHub画面へ入力します。
  5. Recovery codes（回復コード）を、自分だけが管理できる安全な場所へ保存します。スマートフォンを紛失した場合などに必要になります。共用PCのダウンロードフォルダーや実験用共有フォルダーだけを保存先にしないでください。
  6. 保存を確認するボタンで設定を完了します。設定画面で二要素認証が有効になったことを確認してください。

QRコード、設定キー、回復コード、パスワードは提出しません。 教員や班員にも渡さないでください。認証端末を持っていない人や設定できない人は、他人のスマートフォンに登録せず、教員へ相談してください。公式：二要素認証の設定

6. 授業の招待を受ける

Section titled “6. 授業の招待を受ける”
  1. 自分のプロフィールを開き、ユーザー名とURLを確認します。URLはhttps://github.com/自分のユーザー名の形です。
  2. 教員指定の提出先へ、氏名・出席番号・GitHubユーザー名・プロフィールURLを伝えます。学校メールの設定画面や認証画面の画像は不要です。
  3. 教員から、授業用オーガニゼーションE4PBL-CyberSecurityへの招待を受けたら、自分のアカウントでログインし、招待先の名前を確かめて承諾します。オーガニゼーションは、授業用リポジトリをまとめるグループです。
  4. 教員から案内された教材を開き、閲覧できることを確認します。

完了チェック

Section titled “完了チェック”
  • 自分のGitHubアカウントへログインできる。
  • 学校メールが登録され、認証済みになっている。
  • メール非公開の設定を確認した。
  • 二要素認証を設定し、回復コードを安全に保存した。未完了なら教員に相談した。
  • ユーザー名とプロフィールURLを教員に伝えた。
  • 招待後、授業用リポジトリの閲覧を確認した。

共用PCで作業を終えるときはGitHubからSign outし、学校メールもログアウトしてください。回復コードを共用PCへ一時保存した場合は、自分の安全な保存先に移せたことを確認してから、一時ファイルを削除します。

7. 困ったとき

Section titled “7. 困ったとき”
表A-1 GitHub登録・認証のトラブルと対応
状況対応
メールが届かないアドレスの誤入力、迷惑メール、隔離を確認。再送を試し、解決しなければ教員へ相談
メールが既に使われている以前のアカウントを確認。別人のアカウントを変更しようとせず教員へ相談
ユーザー名が使えない別の英数字の組み合わせに変更。メールアドレスやパスワードを名前にしない
アプリのコードが通らないGitHub用の登録か、コードが更新されていないか、端末の時刻が正しいか確認
招待された教材が404になる自分のログイン、招待の承諾、教員によるアクセス権の設定を確認
学校メールが将来使えなくなる利用終了前に、自分が受信できる別メールを追加・認証し、回復手段を確認

相談するときは、操作した項目とエラーメッセージを伝えてください。画面を見せる場合も、パスワード・コード・QRコードは隠します。
