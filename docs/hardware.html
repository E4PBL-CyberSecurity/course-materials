3. ハードウェアをそろえる

嶋 直樹　E4 PBL v2.1 / 2026-10-25

印刷・配布用PDF

第2章の配線を作れるよう、1班分の機器を机にそろえる。電源と機器番号を確認し、まだネットワークを完成させない。

表3-1 1班分の機器と準備事項
機器数量・役割準備すること
ThinkPad E530cとACアダプター1台。日本語キーボード搭載。VyOSルーター本体有線NICを外側に使う。第5章の最初に日本語配列を設定する
USB Ethernetアダプター1個。内側NIC型番・MAC・接続口を記録する
スイッチングハブと電源班専用1台共通スイッチと区別する
Windows 11 PCと電源2台。PC1／PC2ThinkPadとは別に用意する
LANケーブル通常4本外側1、内側1、PC用2。リンクLEDを確認する
インストーラーUSB1個。VyOSのISOを書き込む「インストーラーUSB」の札を付ける
インストール先USB1個。VyOSをインストールし、授業中の起動・設定保存に使う「インストール先USB」の札を付ける

インストール先USBは16GB以上の授業指定品を使う。インストーラーUSBにもISOを書き込める空き容量が必要。2個とも消してよい媒体であることを確認する。

ThinkPadの内蔵SSDはインストール先にしない。2個のUSBメモリの役割は交換しない。必要なデータが入っていれば作業前に退避する。

完了の確認

Section titled “完了の確認”

PC1・PC2、外側・内側NIC、インストーラーUSB・インストール先USBの札を班員と確認する。
