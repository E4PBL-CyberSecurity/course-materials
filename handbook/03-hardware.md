# 3. ハードウェアをそろえる

第2章の配線を作れるよう、1班分の機器を机にそろえる。電源と機器番号を確認し、まだネットワークを完成させない。

表3-1 1班分の機器と準備事項

| 機器 | 数量・役割 | 準備すること |
| --- | --- | --- |
| ThinkPad E530cとACアダプター | 1台。日本語キーボード搭載。VyOSルーター | 本体有線NICを外側に使う。第5章の最初に日本語配列を設定する |
| USB Ethernetアダプター | 1個。内側NIC | 型番・MAC・接続口を記録する |
| スイッチングハブと電源 | 班専用1台 | 共通スイッチと区別する |
| Windows 11 PCと電源 | 2台。PC1／PC2 | ThinkPadとは別に用意する |
| LANケーブル | 通常4本 | 外側1、内側1、PC用2。リンクLEDを確認する |
| インストーラーUSB | 1個。VyOSのISOを書き込む | 「インストーラーUSB」の札を付ける |
| インストール先USB | 1個。VyOSをインストールし、授業中の起動・設定保存に使う | 「インストール先USB」の札を付ける |

インストール先USBは16GB以上の授業指定品を使う。インストーラーUSBにもISOを書き込める空き容量が必要。2個とも消してよい媒体であることを確認する。

ThinkPadの内蔵SSDはインストール先にしない。2個のUSBメモリの役割は交換しない。必要なデータが入っていれば作業前に退避する。

## 完了の確認

PC1・PC2、外側・内側NIC、インストーラーUSB・インストール先USBの札を班員と確認する。
