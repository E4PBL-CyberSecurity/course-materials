# ネットワーク構築の手順

2026年度 E4 PBL サイバーセキュリティ

初めて作業する人は、下表の1から11まで順番に進める。各章の「完了の確認」を記録してから次へ進もう。途中で止まったときは、章番号・操作した機器・コマンド・エラーを教員へ示す。パスワードや秘密鍵は記録しない。

実習の前に、[英単語の事前学習](../vocabulary/preparation.md)で、コマンドや表示に出てくる語の意味を確かめる。[英単語一覧](../vocabulary/words.md)と[表示メッセージの読み方](../vocabulary/messages.md)は実習中にも参照できる。

表0-1 実験手順の順序と各段階の完了条件

| 順序 | 手順書 | 完了の目印 |
| --- | --- | --- |
| 1 | [資料へのアクセス手段を準備する](01-access.md) | 教材と第2章を開ける |
| 2 | [実験用ネットワークを確認する](02-network.md) | 自班のIPと機器の役割を説明できる |
| 3 | [ハードウェアをそろえる](03-hardware.md) | ThinkPad、USB NIC、PC2台、USBメモリ2個を識別できる |
| 4 | [インストーラーUSBを作る](04-media.md) | インストーラーUSBにISOを書き込み、インストール先USBを初期化できる |
| 5 | [インストール先USBへVyOSをインストールする](05-install.md) | インストール先USBだけでVyOSが起動する |
| 6 | [ルーターの設定1：NIC・IP・SSH](06-router1.md) | NICと接続口が対応し、設定を保存できる |
| 7 | [配線を変更しWindowsに固定IPを設定する](07-cabling.md) | Windowsから自班ルーターへ通信できる |
| 8 | [SSHでルーターへサインインする](08-ssh.md) | 接続・終了・公開鍵認証を確認できる |
| 9 | [ルーターの設定2：経路・DNS](09-router2.md) | IP疎通と自班の名前解決を確認できる |
| 10 | [VS Codeを準備する](10-vscode.md) | 記録ファイルを編集しターミナルを使える |
| 11 | [WSLでKali Linux・Ubuntuを準備する](11-wsl.md) | Linuxの登録名・ユーザー・ミラーモード・IP・経路・DNSを確認できる |

例は班1。班2～4は第2章の表でアドレス・ドメインを読み替える。共通GWの`192.168.1.1`は変更しない。

任意の追加設定として、第9章の完了後に[班LANのDHCP](../network-construction/dhcp.md)を導入できる。配布範囲は各班の`.100`～`.199`。PC1・PC2の固定IPは維持する。

GitHubでは上表から各Markdownを開きます。ネットワーク構築は第11章までで完了です。
