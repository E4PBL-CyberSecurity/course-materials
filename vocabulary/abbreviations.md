# コマンド名と略語の補助一覧

[英単語一覧](words.md)とは別に、短縮名や道具の名称を調べるための表です。一般的な英単語の意味を答える最初の課題では、略語の正式名称の暗記は求めません。

## 補助一覧 1

表G-1 短縮名と道具の役割

| 表記 | 言葉としての手がかり | 実習での役割 |
| --- | --- | --- |
| `apt` | 一般語の和訳ではなく名称として扱う | Ubuntuなどのソフトの導入・更新 |
| `cat` | concatenate：連結する、に由来 | ファイルの内容表示・連結 |
| `cd` | change directory：作業場所を変える | 作業ディレクトリーの変更 |
| `chmod` | change mode：権限を変える | ファイルの権限変更 |
| `curl` | 道具の名称として扱う | URLを指定したデータの送受信 |
| `db` | database：情報を整理して蓄えるもの | 実験用データベース |
| `dns` | Domain Name System：名前に関する仕組み | 名前とIPなどの対応を調べる |
| `dpkg` | 道具の名称として扱う | Debian系のパッケージ管理 |

## 補助一覧 2

表G-2 短縮名と道具の役割

| 表記 | 言葉としての手がかり | 実習での役割 |
| --- | --- | --- |
| `env` | environment：環境 | 環境変数 |
| `getent` | 道具の名称として扱う | 名前解決などのシステム情報を取得 |

| `id` | identificationなど：識別 | 利用者や対象を識別する値 |

| `ipconfig` | IP＋configuration：IPの設定 | WindowsのIP設定を表示 |
| `keygen` | key generation：鍵の生成 | SSH用の鍵を作成 |
| `lsblk` | list＋block：ブロック装置の一覧 | ディスクなどを表示 |

## 表示と復旧に出る短縮名

表G-5 表示の短縮名と復旧用の道具

| 表記 | 言葉としての手がかり | 実習での役割 |
| --- | --- | --- |
| `whoami` | who am I：私は誰か | 実行中の利用者名を表示 |
| `passwd` | password：パスワード | パスワードの設定・変更 |
| `RM` | removable：取り外し可能な | 装置の属性。USB接続かどうかの欄ではない |
| `RO` | read only：読み取り専用 | 書き込みを行えるかの属性 |
| `MAJ:MIN` | major・minor：大きい側・小さい側 | 装置を区別する番号。インストール先の選択には使わない |

出典：[第5章](../handbook/05-install.md)、[第11章](../handbook/11-wsl.md)。
