# ネットワーク構築：教員の準備

公開教材の第1〜11章に対応する準備一覧です。学生の実行結果を確認し、操作場所と設定保存を区別して案内します。

## 1. 資料・機器・共通ネットワークを準備する

表L-1 資料・設備・共通設定の準備

| 作業 | 行うこと・完了の確認・参照先 |
| --- | --- |
| □ 資料の閲覧 | 公開ネットワーク教材のURLを案内し、サインインなしで閲覧できることを確認する。非公開の実験教材では別途GitHubのユーザー名を受け取り、招待と承諾を確認する。[第1章](../handbook/01-access.md) |
| □ 班と機器 | 班・端末A/B・IP・ドメインを割り当てる。ThinkPad、USBネットワークアダプター、スイッチ、Windows PC、ケーブル、インストーラーUSB・インストール先USBをそろえる。[第2章](../handbook/02-network.md)・[第3章](../handbook/03-hardware.md) |
| □ VyOSのISO | 指定ISOを`\\192.168.1.10\images\VyOS`に用意し、共有の資格情報を案内する。学生はRufusから共有上のISOを直接選択する。[第4章](../handbook/04-media.md#共有フォルダーのisoを確認する) |
| □ WSLイメージ | 公式配布元から取得・照合したKali LinuxとUbuntuのイメージを、共有の`images\kali`・`images\ubuntu`に用意する。ファイル名とSHA256を手順書と照合する。[第11章](../handbook/11-wsl.md#kali-linuxのイメージを取得する) |
| □ Windowsの条件 | 学生本人が管理者権限で導入でき、WSL 2・ミラーモードを使う条件を満たすことを確認する。[第11章](../handbook/11-wsl.md#wsl本体をインストールする) |
| □ 共通GWの経路 | 班LANへの戻り経路と、共通GWでの外部向けNATを準備する。同じIPを使うE3機器との同時接続を避ける。[第2章](../handbook/02-network.md) |
| □ 共通DNS | 各班へのNS・グルーレコード・転送先、DNSの待受・受付、UDP/TCP 53の通信を確認する。既存の管理経路とLAN25～29の設定を維持する。[DNS別冊 第5節](../network-construction/dns.md#5-教員が共通gwに委任と転送先を準備する) |
| □ 任意・班LANのDHCP | 第9章完了後に実施する。各班ルーターで自班LANの`.100`～`.199`だけを配布し、GW・DNSは自班の`.1`とする。範囲内の手動設定と別DHCPサーバーの混在を避ける。取得IP・MAC・リース・疎通・DNSを確認し、PC2で試した場合は固定IPの`.11`へ戻す。[DHCP別冊](../network-construction/dhcp.md) |
| □ 共有サーバーへの到達 | 班LANから配布共有へ到達できる戻り経路と、サーバー側の受付・資格情報を確認する。[第11章](../handbook/11-wsl.md#kali-linuxのイメージを取得する) |


## 構築後に結果を確認する

各章の完了条件と、配線・IP・経路・DNS・SSH・WSLの確認結果を照合します。実験用サービスの導入・受信許可・実験の停止と評価は、非公開の実験教材で管理します。
